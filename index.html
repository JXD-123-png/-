数据备份与迁移

数据保存在本机浏览器；换电脑或清理浏览器前请先导出

开启后：每次打开平台，如果在「最近记录的交易日」到今天之间有交易日没录，平台会自动拉取并入库（涨停/跌停/炸板家数、连板梯队、板块统计、指数、涨停池明细），不用你每天手动点。
· 平台为单文件、零依赖，可离线运行，数据不会上传到任何服务器，也不需要联网。
· 数据写入浏览器 localStorage，永久保存在本机，除非手动清空或浏览器清理站点数据。
· 建议每周导出一次 JSON 备份，导出文件可随时导入还原。导入为「整表覆盖」，导入前请先导出当前数据留底。
· 不同浏览器（Edge / Chrome / Firefox）之间的数据互不相通，需通过导出/导入迁移。
· 想换电脑看：点「导出『含数据单文件』」，会生成一个新的 html，里面带着全部数据，拷到手机或别的电脑双击打开就能看（在手机上只读浏览，录入还在这台设备上做）。
· 想换电脑继续录入：在该电脑上打开 html，再用「导入 JSON 备份」把数据导进去即可。
指标口径与计算规则

一、赚钱效应指数（0–100）

由 5 个分项加权构成，分数越高说明当日做多资金越容易赚钱：

涨停家数 ÷ 80 × 28（上限 28）
＋ 连板家数 ÷ 35 × 17（上限 17）
＋ 最高连板 ÷ 8 × 13（上限 13）
＋ 平均晋级率 × 17（上限 17）
＋ (昨涨停溢价 ＋ 6) ÷ 16 × 25（上限 25）

二、亏钱效应指数（0–100）

跌停家数 ÷ 40 × 30（上限 30）
＋ 炸板率 × 30（炸板率＝炸板 ÷（涨停＋炸板））
＋ 昨涨停今日下跌家数 ÷ 20 × 25（上限 25）
＋ max(－沪指涨跌幅 ÷ 3, 0) × 15（上限 15）

三、情绪温度与周期阶段

情绪温度 ＝ 赚钱效应指数 － 亏钱效应指数，取值区间约 －100 ～ 100，阶段划分：

≥ 45 高潮　｜ 20～45 升温　｜ 5～20 修复　｜ －5～5 平衡
－20～－5 分歧　｜ －45～－20 退潮　｜ ≤ －45 冰点

四、连板效应与晋级率

「N 进 N+1 晋级率」＝ 次日 (N+1) 板家数 ÷ 当日 N 板家数。晋级率高说明资金愿意承接高度，连板效应强；晋级率骤降说明高度断层、接力亏钱。

连板家数＝连板数 ≥ 2 的个股合计；最高连板＝当日梯队中的最大连板数，是市场情绪空间高度的直接体现。

五、龙头 / 补涨龙 / 首板二板的判定（按情绪与市场认可）

平台不靠涨幅大小自动点名，而是按「市场认不认」来记，标准是：

龙头：板块里启动最早的那只，而且每次分歧都是它先扛住——先回封、先反包、先止跌，资金默认看它的脸色。
补涨龙：在龙头断板之后才卡位出来的那只，龙头退位后由它接力引领板块。
首板 / 二板：补涨龙后面的梯队，是板块的纵深；梯队越完整，板块越能走远。

板块是关键维度，必须分开看：消费看金健米业、医药看哈药股份、汽车零部件看襄阳轴承——各自一条线，不要混在一起。录入时按板块分别记角色、连板数、涨幅、状态。

「分歧扛住次数」用来量化龙头成色：每经历一次板块分歧它还先扛住，次数就 +1，次数越多越像真龙头。

六、龙头的赚钱效应与亏钱效应

核心只看一件事：龙头里面有没有人亏大钱。

龙头出现大亏（勾选「出现大亏」，或当日涨幅 ≤ －5%）→ 龙头亏钱效应
龙头没大亏，还在封板 / 加速 / 回封 → 龙头赚钱效应延续
补涨龙同理：补涨龙开始大亏，通常是这波板块行情进入尾声

龙头（尤其是空间板）一旦大亏，等于最强的那批资金开始亏钱，情绪大概率要退潮——这是平台上最该警惕的信号。龙头榜会给出每只标的的「大亏次数」与「最大单日跌幅」。

七、9:25 竞价怎么用

「9:25 竞价」页自动把上一交易日的板块龙头、补涨龙、首板二板列成候选，你只填竞价涨幅，平台立刻给判断：

≥ +3%　竞价强：注意是否一致性强、会不会一字
0 ～ +3%　竞价偏强：看开盘后承接
－2% ～ 0　小幅低开：看分时能不能回封
≤ －2%　竞价弱：该强不强，警惕兑现
该弱不弱 ＋ 竞价 ≥ +2%　重点跟踪

填完点「保存竞价到该日」，数据落到当天记录里；收盘后再到「每日录入」补涨幅和状态即可。

八、该弱不弱 → 次日主动转强

该弱不弱：大盘或板块明显走弱（涨停减少、炸板增多、外面一片跌），但这只票该跌没跌——没跟跌、守住、甚至回封。这类票往往是次日主动转强的种子。

用法：在「每日录入」勾选「该弱不弱」，平台自动去下一交易日的记录里找这只票，判断是否主动转强（封板 / 加速 / 反包，或涨幅 ≥ +5%），并统计转强胜率。记几周就知道哪种「该弱不弱」最值钱。

九、每天怎么用

9:25 竞价后：打开「9:25 竞价」填竞价涨幅并保存，重点看昨天标记「该弱不弱」的那几只有没有竞价转强。
收盘后：到「每日录入」补涨停跌停家数、连板梯队、板块涨停统计，逐板块记龙头 / 补涨龙 / 首板二板，勾选「出现大亏」「该弱不弱」。
复盘：「情绪总览」看周期位置，「板块龙虎」找还在走强的板块，「龙头榜」确认龙头有没有大亏，「连板效应」看高度有没有断层。

十、一键拉取（行情数据源）

「每日录入」页右上角「⚡ 一键拉取行情」会自动联网取数并填好：

涨停家数 / 跌停家数 / 炸板家数 ← 东方财富 涨停池 / 跌停池 / 炸板池
连板梯队（1 板、2 板 … 最高板）← 涨停池里每只个股的连板数
板块涨停统计 ← 涨停池按行业板块归并（含跌停板块）
沪指涨跌幅、两市成交额 ← 腾讯行情指数接口
昨涨停股今日平均溢价、昨日涨停今日下跌家数 ← 自动回溯上一交易日涨停池，逐只取今日涨跌幅求平均
9:25 竞价涨停家数 ← 首次封板时间 ≤ 9:30 的家数

拉取后下方出现「当日涨停池明细」，勾选后点「加入勾选的涨停股」，平台按连板数预填角色（≥3 板＝龙头、2 板＝二板、首板＝首板），再由你人工确认真正的龙头 / 补涨龙。

「9:25 竞价」页的「⚡ 一键拉取竞价」用今开与昨收自动算竞价涨幅（竞价涨幅＝(今开－昨收)÷昨收）。

数据源说明：东方财富公开行情接口（涨停 / 跌停 / 炸板池）、腾讯行情接口（实时价、今开、昨收、指数）；同花顺涨停池作为可选增强（能带出涨停原因 / 题材），不可用时自动降级为东方财富的行业板块。同花顺 PC 客户端的数据是私有本地文件，读不了。一键拉取需要联网；离线时不影响手工录入。

录入字段说明

市场数据

涨停家数：不含一字未开板的统计口径按自己习惯即可，关键是保持前后一致。炸板家数：盘中曾涨停但收盘未封住的家数。

昨日涨停股今日平均溢价：昨日涨停个股今日的算术平均涨跌幅，是「接力是否赚钱」最直接的指标，负数代表接力亏钱。

连板梯队

按连板数分别填写家数，例如「1 板 30 家、2 板 8 家、3 板 3 家、4 板 1 家」。家数为 0 的档位可以不填。

板块与角色

板块：填板块名（消费 / 医药 / 汽车零部件 / 房地产……），同一板块的票要写同一个名字，平台才能按板块归并。

角色：龙头＝启动最早、分歧先扛住的那只；补涨龙＝龙头断板后卡位的那只；首板 / 二板＝补涨龙后面的梯队；中军＝大市值机构票；其他＝高标、跟风前排等。

分歧扛住次数：板块每分歧一次它还先扛住，就 +1。龙头启动日：它第一根涨停（或首次异动）那天，用来判断启动早晚。

竞价与标记

竞价涨幅：9:25 集合竞价结束后的开盘涨幅，盘前在「9:25 竞价」页填更省事。

出现大亏：这只票里有人亏大钱了就勾上（也可以不勾，平台对当日跌幅 ≤ －5% 会自动标）。这是判断龙头亏钱效应的核心。

该弱不弱：大盘 / 板块走弱但它该跌没跌，就勾上；平台会自动跟踪它次日是否主动转强。

状态

强势、加速、封板、反包属于正反馈；分歧、炸板、断板、走弱、跌停属于负反馈。同一天先分歧后回封的，取收盘时最接近的状态即可。
